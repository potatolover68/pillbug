# 0.5.0 (2026-08-18)

- `@nodish/core` has been bumped to 0.6.0. Major version bump because I (MSK) am also the sole maintainer of that package.
- Features arising from the version bump include frames (similar to the ones in [Blender](https://docs.blender.org/manual/en/latest/interface/controls/nodes/types/layout/frame.html)) and the add node menu automatically opening on one-ended connections.
