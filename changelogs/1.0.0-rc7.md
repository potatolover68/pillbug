# 1.0.0-rc7 (2026-09-04)

- The philosophy regarding template nodes has been changed. Previously, I attempted to make them as flexible as possible by providing nodes for every basic operation. This, of course, doesn't work, especially with the current tree-based template parser, since there are a billion, trillion edge cases to handle. I don't want to make that effort. Sorry. Thus, I'm switching back to the old content-in, content-out approach.
- Most of the confusing template nodes using the `Templates` type have been deprecated, and will be removed soon™ (whenever v1.0.0 is released). Ergo: don't use them.
- To replace them are more traditional nodes in line with the current rename parameter nodes.
