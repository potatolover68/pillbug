# 0.6.0 (2026-08-22)

- RETF node has been tweaked to use JWB's [RETF exceptions](https://github.com/wikimedia-gadgets/JWB/blob/master/RETF/RETF.js).
- You can now keep/discard individual changes in the Review tab.
- Hotkeys have been added to the Review tab, see below.
  - Save: `Space`
  - Skip: `Escape`
  - Start/Stop Batch: `b`
  - Toggle Edit: `e`
  - Toggle Preview: `p`
  - Toggle Minor: `m`
  - Toggle Bot: `o`

- Edit summary:

  - Focus Summary: `s`
  - Blur Summary: `Escape`

- Diff Navigation:

  - Next Hunk: `n`
  - Previous Hunk: `N`
  - Scroll Down: `j`
  - Scroll Up: `k`
  - Page Down: `PageDown`
  - Page Up: `PageUp`
