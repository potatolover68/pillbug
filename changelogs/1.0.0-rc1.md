# 1.0.0-rc1 (2026-08-25)

- Tours are now available throughout the app:
  - A welcome tour runs once on first visit, and can be replayed from the `?` in the sidebar tab bar.
  - Config, Generator & page queue, Code, and Review each have their own deeper tour (orange `?` next to Config/Generator titles, or bottom-left of the Code/Review panes).
- The About row's former wiki docs link now opens the in-app changelog instead.
- Queue generator simplifications:
  - Category no longer has separate pages / subcategories / files checkboxes, as this is wholly redundant with the namespace filters.
  - The "Pages with prefix" generator was removed as it was redundant with the Wiki search.
