# 1.0.0-rc3 (2026-08-29)

- A couple new nodes: `ai/realize-newlines` and `wiki/replace-deprecated-parameters`.
  - `ai/realize-newlines` converts literal escape sequences (\\n, \\r\\n, \\r) in the text into real newlines.
  - `wiki/replace-deprecated-parameters` fetches and caches a template's `{{#invoke:Check for deprecated parameters}}` rules, then applies the relevant fixes to parameters to that template.
- AI choose can now handle newlines. Whoops.
- You can now toggle live evaluation of the graph. It can help find bugs; however, it can also slow down the UI if there are nodes that interact with the network (e.g. the AI nodes).
